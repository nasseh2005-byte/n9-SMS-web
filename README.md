# N9 SMS Web

واجهة عربية لإدارة أرشيفات SMS، فصل رسائل الشركات، البحث والمطابقة من Excel، إنشاء رسائل يدوية، ومعاينة وتصدير الأدلة بثيمات Android وHuawei وiPhone.

## التشغيل المحلي

```bash
npm ci
npm run dev
```

## الاختبارات والبناء

```bash
npm test
npm run build
npm run build:vercel
```

## النشر على Vercel

المستودع مجهز للاستيراد المباشر من GitHub إلى Vercel:

1. افتح **Add New → Project** في Vercel.
2. استورد `nasseh2005-byte/n9-SMS-web`.
3. اترك إعدادات البناء من `vercel.json` كما هي.
4. اضغط Deploy.

يستخدم Vercel الأمر `npm run build:vercel` وينشر `dist/client` تلقائياً.

### وضع البيانات على Vercel

نسخة Vercel الحالية تعمل بوضع **محلي داخل المتصفح** كي تعمل شاشة الدخول وكل أدوات المشروع من دون الاعتماد على Cloudflare D1/R2. لذلك:

- الحسابات والشركات والرسائل التي تنشئها على Vercel تُحفظ في IndexedDB داخل المتصفح نفسه.
- لا تنتقل هذه البيانات تلقائياً إلى جهاز أو متصفح آخر.
- لا تُخزن بيانات SMS في GitHub أو Vercel في هذا الوضع.
- استخدم النسخة الخاصة الحالية ذات D1/R2 عندما تحتاج مشاركة حقيقية بين الأجهزة والمستخدمين.

لا تجعل مستودعاً يحوي بيانات عملاء أو ملفات XML حقيقية عاماً. ملفات XML وPDF الأصلية ليست مضمنة في هذا المستودع.

المستودع الحالي ظاهر للعامة. أبقِ فيه كود التطبيق والبيانات التجريبية فقط، وغيّر ظهوره إلى **Private** قبل إضافة أي ملف عمل حقيقي أو إعداد سري.
